# Demo Sanat Showcase

Visual Reference

Build a premium RTL Persian website demo for an industrial machinery company.

IMPORTANT:
The brand name displayed throughout the entire website MUST be:

"دمو صنعت"

Do NOT use "کوشش کاران" anywhere as a visible brand name.
Do NOT use "Kooshesh Karan" as the company/brand name.

The attached reference image is the PRIMARY visual reference.
Use it to understand the visual style, layout, spacing, color palette,
product presentation and overall premium industrial feeling.

==================================================
PROJECT GOAL
==================================================

Create ONLY THREE fully designed pages:

1. صفحه اصلی
2. محصولات
3. تماس با ما

The website is a high-quality DEMO for an industrial packaging machinery company.

The final design should feel:
- Premium
- Modern
- Industrial
- Minimal but creative
- Elegant
- Professional
- Trustworthy
- Visually distinctive

Avoid making the design too neutral, empty or boring.

Use creative visual details while maintaining a clean professional appearance.
